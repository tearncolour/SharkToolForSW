# 9. 开发指南

## 9.1 添加新命令

**插件端**：

1. 在 ElectronServer.cs 的 HandleCommandAsync 方法中添加 case：

```csharp
case "my-new-command":
    {
        var param = payload?["param"]?.ToString();
        // 执行操作
        result = new { success = true, data = "结果" };
    }
    break;
```

**客户端**：

2. 通过 IPC 调用命令：

```javascript
const result = await window.electronAPI.sendCommand('my-new-command', {
    param: 'value'
});
```

## 9.2 添加新面板

1. 创建 Vue 组件：

```vue
<!-- renderer/components/MyPanel.vue -->
<template>
  <div class="my-panel">
    <!-- 面板内容 -->
  </div>
</template>

<script setup>
import { ref, onMounted } from 'vue';
// 组件逻辑
</script>

<style scoped>
.my-panel {
    /* 样式 */
}
</style>
```

2. 在 App.vue 中注册：

```vue
<script setup>
import MyPanel from './components/MyPanel.vue';
</script>

<template>
  <div v-show="currentView === 'myView'" class="panel-content">
    <MyPanel />
  </div>
</template>
```

## 9.4 性能优化与最佳实践

**1. 资源锁定管理**
在访问 SolidWorks 特征的详细定义数据（如 `GetDefinition`）后，必须显式调用 `ReleaseSelectionAccess`，否则会导致特征被锁定，用户无法手动操作（如压缩/解压缩）。

```csharp
var featData = feature.GetDefinition();
try {
    featData.AccessSelections(_activeDoc, null);
    // 读取数据...
} finally {
    featData.ReleaseSelectionAccess(); // 必须释放！
}
```

**2. 防止界面闪烁**
在进行大量 API 调用或遍历特征树时，应暂时禁用图形更新：

```csharp
var view = _activeDoc.ActiveView;
if (view != null) view.EnableGraphicsUpdate = false;
try {
    // 执行操作...
} finally {
    if (view != null) view.EnableGraphicsUpdate = true;
}
```

**3. 避免鼠标忙碌状态**
后台轮询任务应尽量轻量化（浅层扫描）。避免在轮询中调用会触发 SolidWorks 状态改变的 API（如 `AccessSelections`），这会导致鼠标光标频繁变为"忙碌"状态。建议结合事件驱动（`AddItemNotify`, `ModifyNotify`）来进行深度扫描。
