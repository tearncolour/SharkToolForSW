# 6. 功能模块

## 6.1 历史记录追踪

**工作流程**：
1. 文档打开时，EnhancedHistoryTracker 开始追踪
2. **混合监控机制**：
   - **浅层轮询**：定时器（1.5秒间隔）仅检查特征数量、压制状态等基本属性，避免触发 SolidWorks "忙碌"光标。
   - **事件驱动**：监听 `AddItemNotify` 和 `ModifyNotify` 事件，当检测到实际变更时触发深度扫描。
3. **深度扫描**：
   - 仅在必要时（事件触发或新增特征）执行。
   - 获取详细参数（如拉伸深度、圆角半径）。
   - **防闪烁处理**：扫描期间禁用视图更新 (`EnableGraphicsUpdate = false`)。
   - **资源安全**：读取特征数据后立即释放选择权限 (`ReleaseSelectionAccess`)，防止资源锁定。
4. 发现变化时创建 FeatureChangeRecord
5. 触发相应事件（OnFeatureAdded/Deleted/Modified）
6. 记录保存到 LiteDB 数据库
7. 通过 WebSocket 推送到 Electron 客户端

**回滚机制**：
1. 用户选择历史快照
2. 调用 RollbackToSnapshot 方法
3. 压制当前所有特征
4. 按顺序恢复快照中的特征

## 6.2 文件转换

**STEP 转 SLDPRT 流程**：
1. 接收转换请求（文件路径）
2. 使用 LoadFile4 静默导入 STEP 文件
3. 使用 SaveAs3 保存为 SLDPRT 格式
4. 关闭临时文档（保留用户原有文档）
5. 返回转换结果

## 6.3 缩略图提取

**方法**：
1. 使用 Shell32 COM 接口提取嵌入缩略图
2. 转换为 Base64 编码的 PNG 图片
3. 缓存到内存避免重复提取
